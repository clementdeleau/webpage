# Clément Deleau, personal webpage

Live at https://clementdeleau.github.io/webpage/

A single-page professional site (`index.html`, no build step). Edit the placeholder text in `index.html`, commit, and GitHub Pages republishes it within a minute or two.

To use a photo instead of the "CD" initials, add `photo.jpg` to the repo and replace the `<span class="initials ...">CD</span>` line with `<img src="photo.jpg" alt="Clément Deleau">`.
